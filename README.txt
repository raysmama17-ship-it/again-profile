다시, 나 — 프로필 페이지

1. ZIP 파일을 압축 해제합니다.
2. again-profile 폴더를 VS Code의 '폴더 열기'로 엽니다.
3. index.html을 우클릭하고 'Open with Live Server'를 선택합니다.
   index.html을 브라우저에서 직접 열어도 페이지를 볼 수 있습니다.

파일 구성
index.html       : 내용과 시맨틱 구조
css/style.css    : 디자인, 색상 변수, 반응형 스타일 (영역별 한글 주석)
js/script.js     : 모바일 메뉴, 스크롤 헤더
images/          : 첨부 이미지 5개

수정 방법
- 일반 텍스트: index.html에서 수정합니다.
- 색상: css/style.css 맨 위 :root 변수를 수정합니다.
- 모바일 기준: 767px 이하. 768px 이상에서는 메뉴가 항상 보입니다.
- 헤더 높이: 모든 화면에서 115px입니다.
- 헤더 배경은 스크롤 전후 모두 #acaaab 회색을 유지합니다.
- PC에서는 페이지 전체가 최대 780px 폭으로 가운데 정렬됩니다.
- 헤더와 푸터도 같은 780px 폭을 사용하며 위로 버튼도 그 안에 배치됩니다.
- 화면이 780px보다 작으면 페이지가 화면 폭에 맞게 줄어듭니다.
- 바깥 여백만 기기의 밝은 모드에서는 흰색, 어두운 모드에서는 검정입니다.
- 페이지 내부의 네온라임·흰색·짙은 회색 디자인은 모드에 관계없이 유지됩니다.
- 메인 이미지의 이름과 소개 문구는 이미지에 포함되어 있습니다.
- 원본 HTML의 저작권 문구(김지은)를 시안대로 유지했습니다.

문의에는 이름, 이메일, 문의 내용 입력 폼이 있습니다.
이름 필수 입력, 이메일 형식, 문의 내용 10자 이상을 확인합니다.
실제 이메일 전송 서비스는 연결되지 않았으므로 입력 확인만 수행합니다.
전송됐다는 문구를 표시하거나 입력 내용을 초기화하지 않습니다.

Google Fonts는 인터넷 연결이 필요합니다.
폰트 연결이 안 되면 기기의 기본 sans-serif 글꼴로 표시됩니다.
원본 이미지 크기를 유지했으며 확대 화면에서의 선명도는 원본 해상도에 따릅니다.
